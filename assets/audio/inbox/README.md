# Audio inbox
Upload real sounds here from your phone. Full steps: docs/AUDIO.md.

1. Name the file what the game calls the sound: `click.mp3` replaces `click`. Music starts with `music_`.
2. Put it in the folder for where it came from: `elevenlabs/`, `suno/`, or `other/`.
3. Commit to main. A robot converts it, removes it from here, and rebuilds the game.
